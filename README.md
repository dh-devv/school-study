# School Study 📚

고등학교 내신 대비와 복습을 위한 과목별 학습 자료입니다.

## 과목별 자료

| 과목 | 주요 내용 |
| --- | --- |
| 국어 | 문학, 한글 맞춤법 |
| 영어 | 본문, 문법, 서술형 |
| 수학 | 집합과 명제 |
| 사회 | 학습지 정리, 서술형 |
| 과학 | 생물다양성, 화학, 물리 |
| 컴퓨터시스템 | 데이터와 정보, 수의 체계, 이진수의 연산 |

위 내용은 **1학년 자료**를 기준으로 합니다.

## 공부하는 방법

1. 과목별 자료에서 필요한 단원을 선택합니다.
2. 핵심 개념과 표를 읽고 예시를 통해 이해합니다.
3. 자료 끝에 다음 내용 링크가 있다면 순서대로 이어서 학습합니다.
