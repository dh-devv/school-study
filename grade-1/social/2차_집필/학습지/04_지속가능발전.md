# 경제 주체의 역할과 지속가능발전

## 1. 정부의 역할과 책임

정부는 시장 실패를 보완하고 지속가능발전을 위해 정책을 마련한다.

| 역할 | 내용 |
| --- | --- |
| 불공정 거래 규제 | 법률을 제정하고 공정거래위원회 등을 통해 불공정 거래 행위를 규제한다. |
| 공공재 공급 | 공공재를 직접 공급하거나 관리한다. |
| 외부 효과 개선 | 긍정적 외부 효과를 내는 활동은 장려하고, 부정적 외부 효과를 내는 활동은 억제한다. |
| 지속가능발전 추진 | 국가 지속가능발전 목표를 수립하고 이를 실현하기 위한 정책을 추진한다. |

> **코딩으로 연결하기:** 여러 사용자가 함께 쓰는 서비스에서 공통 규칙과 공유 기능이 필요한 것처럼, 정부는 불공정 거래 규제와 공공재 공급 등으로 시장 실패를 보완한다. 실제 정책의 효과와 한계는 별도로 살펴야 한다.

## 2. 기업가의 역할과 책임

| 역할 | 내용 |
| --- | --- |
| 기업가 정신 발휘 | 위험과 불확실성을 감수하며 새로운 기회에 도전하고 기업을 성장시키고자 한다. |
| 사회적 책임 실현 | 관련 법규와 이해관계자의 권리를 존중하고 지역 사회에 공헌한다. |
| 지속가능발전 추진 | 환경 보호, 사회적 책임, 투명한 지배구조를 고려하는 **ESG 경영**을 실천한다. |

## 3. 노동자와 소비자의 역할과 책임

| 주체 | 역할과 책임 |
| --- | --- |
| 노동자 | 자신의 권리를 알고 정당하게 요구하며, 기업가와 협력하여 기업의 발전에 기여한다. |
| 소비자 | **소비자 주권**을 인식하고 상품을 주체적으로 선택한다. 생산부터 사용·처리까지의 영향을 고려하는 **윤리적 소비**를 실천한다. |

## 4. 지속가능발전

**지속가능발전**은 미래 세대가 필요를 충족할 능력을 해치지 않으면서 현재 세대의 필요를 충족하는 발전이다. 정부·기업·노동자·소비자가 각자의 역할을 실천하며 경제, 사회, 환경을 함께 고려해야 한다.

> **미래의 개발자에게 넘길 코드라면?** 지금만 편리하고 나중에 유지할 수 없는 설계는 문제가 된다. 지속가능발전도 현재의 필요와 미래 세대의 필요 충족 능력을 함께 고려한다. 다만 사람과 환경의 문제는 코드 유지보수보다 훨씬 넓다.
