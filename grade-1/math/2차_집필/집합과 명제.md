## 1. 집합과 명제의 주요 기호 정리

| 기호 | 읽는 법 / 명칭 | 의미 및 설명 |
| :---: | :--- | :--- |
| ∈, ∉ | 원소이다 / 아니다 | 원소가 집합에 속하는지 여부 (a ∈ A: a는 A의 원소) |
| ⊂, ⊃ | 포함한다 (부분집합) | 집합 간의 포함 관계 (A ⊂ B: A는 B의 부분집합) |
| ∅ | 공집합 | 원소가 단 하나도 없는 집합 ({ }과 같음) |
| U | 전체집합 | 논의의 대상이 되는 전체 집합 |
| Aᶜ | 여집합 | 전체집합 U 중 A에 속하지 않는 원소들의 모임 (U - A) |
| ∩ | 교집합 (Cap) | 두 집합에 공통으로 속하는 원소들의 모임 (AND) |
| ∪ | 합집합 (Cup) | 두 집합 중 어느 한쪽이라도 속하는 원소들의 모임 (OR) |
| - (또는 ∖) | 차집합 | 집합 A에서 B와 겹치는 부분을 뺀 나머지 (A ∩ Bᶜ) |
| n(A) | 원소의 개수 | 집합 A에 들어있는 원소의 총 개수 |
| ¬p (또는 ∼p) | Not p (부정) | 명제 p가 아니다 (참 ↔ 거짓 반전) |
| p → q | 조건 명제 | "p이면 q이다" (p가 성립하면 q도 성립) |
| p ⇔ q | 필요충분조건 | p → q 이고 q → p 가 모두 성립 (p와 q가 동치) |
| ∀ | 모든 (For all) | 양화사: 모든 원소에 대해 성립함을 의미 |
| ∃ | 어떤 (There exists) | 양화사: 조건을 만족하는 원소가 적어도 하나 존재함을 의미 |

## 2. 집합 (Set)

### 2.1. 필수 개념
* **집합과 원소**: 조건에 따라 대상을 분명하게 정할 수 있는 모임.
* **부분집합**: 집합 A의 모든 원소가 B에 속할 때 (A ⊂ B)
  * **진부분집합**: A ⊂ B 이고 A ≠ B 인 부분집합
* **부분집합의 개수**: 원소의 개수가 n개인 집합 A에 대하여
  * 부분집합 개수: 2ⁿ
  * 특정 원소 k개를 반드시 포함(또는 제외)하는 부분집합 개수: 2ⁿ⁻ᵏ

### 2.2. 집합의 포함관계와 동치 조건 (시험 단골 출제)
다음 조건들은 모두 **완전히 같은 말(동치)**입니다.
* A ⊂ B 이다.
* A ∩ B = A 이다. (교집합은 작은 쪽)
* A ∪ B = B 이다. (합집합은 큰 쪽)
* A - B = ∅ 이다. (차집합을 구하면 남는 것이 없음)
* Bᶜ ⊂ Aᶜ 이다. (여집합을 취하면 포함 방향이 반대)

### 2.3. 집합의 연산 법칙
* **차집합 성질**: A - B = A ∩ Bᶜ
* **드모르간 법칙**:
  * (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ
  * (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ
* **분배법칙**: 
  * A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
  * A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
* **흡수법칙**:
  * A ∪ (A ∩ B) = A
  * A ∩ (A ∪ B) = A
* **여집합의 성질**:
  * (Aᶜ)ᶜ = A
  * A ∪ Aᶜ = U, A ∩ Aᶜ = ∅
  * Uᶜ = ∅, ∅ᶜ = U

### 2.4. 유한집합의 원소의 개수
* n(A ∪ B) = n(A) + n(B) - n(A ∩ B)
* n(A ∪ B ∪ C) = n(A) + n(B) + n(C) - n(A ∩ B) - n(B ∩ C) - n(C ∩ A) + n(A ∩ B ∩ C)

## 3. 명제 (Proposition)

### 3.1. 조건과 조건의 부정
* **명제**: 참과 거짓을 명확히 판별할 수 있는 문장이나 식.
* **조건과 진리집합**: 조건 p(x)를 참이 되게 하는 원소들의 집합 P.
* **조건 명제 p → q의 참/거짓**:
  * 진리집합의 포함관계 P ⊂ Q 이면 명제 p → q는 **참(T)**.
  * P ⊄ Q 이면 **거짓(F)** (이때 P ∩ Qᶜ에 속하는 원소가 **반례**).

### 3.2. 역과 대우
명제 p → q에 대하여:
* **역**: q → p
* **대우**: ¬q → ¬p (또는 ∼q → ∼p)
> **핵심**: 명제와 그 **대우**의 참/거짓은 항상 일치한다. (역의 참/거짓은 원명제와 직접적인 연관이 없음)

### 3.3. 필요조건과 충분조건
진리집합 P, Q에 대해 p → q가 참일 때 (P ⊂ Q):
* p는 q이기 위한 **충분조건** (화살표를 주는 입장)
* q는 p이기 위한 **필요조건** (화살표를 받는 입장)
* P = Q 이면 **필요충분조건** (p ⇔ q)

### 3.4. 양화사(∀, ∃)가 포함된 명제의 부정
* **모든(∀)의 부정**: "모든 x에 대하여 p이다" → 부정: "**어떤** x에 대하여 **¬p**이다"
* **어떤(∃)의 부정**: "어떤 x에 대하여 p이다" → 부정: "**모든** x에 대하여 **¬p**이다"

## 4. 명제의 증명과 절대부등식

### 4.1. 증명법
1. **대우를 이용한 증명법**: 명제 p → q 대신 대우 ¬q → ¬p가 참임을 증명.
2. **귀류법**: 명제의 결론을 부정하여 모순이 생김을 보임으로써 명제가 참임을 증명.

### 4.2. 대표적인 절대부등식
* **산술기하평균 부등식** (a > 0, b > 0 일 때):
  (a + b) / 2 ≥ √(ab)  (즉, a + b ≥ 2√(ab))
  *(단, 등호는 a = b 일 때 성립)*

* **코시-슈바르츠 부등식** (a, b, x, y가 실수일 때):
  (a² + b²)(x² + y²) ≥ (ax + by)²
  *(단, 등호는 a / x = b / y 일 때 성립)*
