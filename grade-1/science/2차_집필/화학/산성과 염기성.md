# 산성과 염기성

## 1. 산과 염기

| 구분 | 물에 녹았을 때 | 수용액의 성질 | 예 |
|---|---|---|---|
| 산 | 수소 이온(H⁺)을 내놓는다. | 산성 | 염산, 황산 |
| 염기 | 수산화 이온(OH⁻)을 생성한다. | 염기성 | 수산화 나트륨, 수산화 칼슘 |

> **핵심:** 산성 수용액의 공통적인 성질은 H⁺, 염기성 수용액의 공통적인 성질은 OH⁻ 때문이다.

### 수용액에서 이온이 생기는 모습

```text
염화 수소(HCl) ──물에 녹음──> H⁺ + Cl⁻
수산화 나트륨(NaOH) ──물에 녹음──> Na⁺ + OH⁻
```

수소 이온은 실제 수용액에서 물 분자와 결합한 형태로 존재하지만, 편의상 H⁺로 나타낸다.

> **코딩으로 연결하기:** 서로 다른 입력을 처리해도 공통으로 나타나는 값을 살펴보듯, 여러 산성 수용액의 공통 성질은 H⁺, 염기성 수용액의 공통 성질은 OH⁻와 연결해 기억하자. 반응식의 표기는 실제 입자의 모습을 단순화한 것이다.

## 2. 산성·염기성 수용액의 공통점

- 수용액 속에서 이온이 이동하므로 **전류가 흐른다.**
- 산성 수용액과 염기성 수용액을 섞으면 H⁺와 OH⁻가 반응하여 물을 생성한다. 이를 **중화 반응**이라고 한다.

> **조건 확인:** 이온이 이동할 수 있는 **수용액**이라는 조건을 놓치지 말자. 코드에서 실행 조건을 확인하듯, 어떤 상태의 물질을 설명하는지 먼저 확인하면 헷갈리지 않는다.
