# 중화 반응

## 1. 중화 반응의 의미

**중화 반응**은 산성 수용액의 수소 이온(H⁺)과 염기성 수용액의 수산화 이온(OH⁻)이 반응하여 물을 생성하는 반응이다.

```text
산성 수용액                         염기성 수용액
수소 이온(H⁺)   +   수산화 이온(OH⁻)
                      ↓
                   물(H₂O)
```

**반응식:** H⁺ + OH⁻ → H₂O

H⁺와 OH⁻는 **이온 수의 비가 1 : 1**로 반응한다. 산과 염기 용액 자체의 부피가 반드시 1 : 1인 것은 아니다.

> **짝 맞추기:** 두 목록에서 H⁺ 하나와 OH⁻ 하나를 짝지어 물이 만들어진다고 생각해 보자. 짝짓는 기준은 용액의 부피가 아니라 반응하는 이온의 수이다.

## 2. 혼합 용액의 액성

반응 전 H⁺와 OH⁻의 양을 비교하면, 반응 후 어느 이온이 남는지 판단할 수 있다.

| 반응 전 이온의 양 | 반응 후 | 혼합 용액의 액성 |
|---|---|---|
| H⁺ > OH⁻ | H⁺가 남는다. | 산성 |
| H⁺ = OH⁻ | 두 이온이 같은 수만큼 반응한다. | 중성 |
| H⁺ < OH⁻ | OH⁻가 남는다. | 염기성 |

> 위 비교는 염산과 수산화 나트륨 수용액처럼 반응 후 남은 다른 이온이 액성에 영향을 주지 않는 경우를 기준으로 한다. 중화 반응이 일어나더라도 한쪽 이온이 남으면 혼합 용액은 반드시 중성이 되지 않는다.

> **자바의 조건문으로 확인:** 위 표의 조건에서 반응 전 이온 수가 각각 5와 3이라면 `5 > 3`이므로 H⁺가 남아 산성이다.

```java
int hydrogenIons = 5;
int hydroxideIons = 3;
String result = hydrogenIons > hydroxideIons ? "산성"
        : hydrogenIons < hydroxideIons ? "염기성" : "중성";
```

이 코드는 위에서 명시한 단순한 경우의 비교를 나타낼 뿐, 모든 용액의 액성을 계산하는 프로그램은 아니다.

## 3. 중화열

중화 반응이 일어날 때 방출되는 열을 **중화열**이라고 한다.

```text
H⁺ + OH⁻ → H₂O + 열
```

같은 산과 염기의 묽은 수용액에서 반응한 H⁺와 OH⁻의 양이 많을수록 방출되는 중화열이 많다. 다만 용액의 온도 상승은 방출된 열뿐 아니라 용액의 양과 주변으로 빠져나간 열에도 영향을 받는다.
