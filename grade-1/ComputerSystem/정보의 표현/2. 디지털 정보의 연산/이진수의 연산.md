# 이진수의 연산

## 1. 이진수의 덧셈

이진수는 0과 1만 사용하므로, 한 자리에서 더한 값이 **2 이상**이면 윗자리로 올림한다.

| 덧셈 | 결과 | 설명 |
| --- | --- | --- |
| 0 + 0 | 0 | 올림 없음 |
| 0 + 1 또는 1 + 0 | 1 | 올림 없음 |
| 1 + 1 | 10 | 현재 자리에 0을 쓰고 1을 올림 |
| 1 + 1 + 1 | 11 | 현재 자리에 1을 쓰고 1을 올림 |

### 계산 예시

```text
    ¹¹       ← 올림
    101
  + 011
  -----
   1000
```

오른쪽 자리부터 더한다. 십진수로 확인하면 **5 + 3 = 8**이다.

> **자바로 확인하기:**

```java
int sum = 0b101 + 0b011;
System.out.println(Integer.toBinaryString(sum)); // 1000
```

`0b`는 이진수 리터럴을 뜻한다. 덧셈 결과의 값은 8이고, `toBinaryString`으로 출력한 `"1000"`은 그 값을 이진수로 나타낸 문자열이다.
